## Project overview

The Power BI report is a Zomato restaurant analytics dashboard containing two report pages.

The dashboard covers:

- Restaurant count
- Total votes
- Average rating
- Online delivery
- Rating groups
- Restaurant count by cuisine
- Average rating by price range
- Restaurant distribution by city
- Average cost for two by country
- Online delivery adoption
- Restaurant count by year
- Table booking adoption
- Top-rated restaurant detail table
- Country filtering

## Opening the project

1. Download the repository.
2. Open `powerbi/zomato_project_itx(1).pbix` with Power BI Desktop.
3. Keep `data/zomato_data_ITX(2).xlsx` available if Power BI requests the source workbook.
4. Open the report pages to interact with the dashboard.
